# WDD131: Dynamic Web Fundamentals

This repository contains my work and assignments for WDD131: Dynamic Web Fundamentals provided by [BYU Idaho](https://www.byui.edu/) online.
It includes the main page related to the course as well which will encapsulate all the assignments and lessons learned throughout these 7
weeks course.

## Purpose of the course

The purpose of this course is to teach how to build responsive and dynamic web pages.

## Content of the repository

### 📚 Weekly Lessons

#### **Week 01: Basic Layout**

- **File**: `week01/basic-layout.html`
- **Focus**: Introduction to HTML structure and basic CSS layout techniques
- **Styles**: `week01/styles/layout.css`

#### **Week 02: Browser Object Model & Media Queries**

- **Files**:
  - `week02/bom.html` - Browser Object Model exploration
  - `week02/debugging.html` - JavaScript debugging practices
  - `week02/media-query.html` - Responsive design with media queries
- **Scripts**: BOM script, debugging utilities
- **Focus**: JavaScript fundamentals, responsive design, debugging techniques

#### **Week 03: Design & Responsive Images**

- **Files**:
  - `week03/design.html` - Design principles
  - `week03/responsive-images.html` - Responsive image techniques
- **Focus**: Advanced CSS design, optimized image delivery for different screen sizes

#### **Week 04: Arrays & Performance**

- **Files**:
  - `week04/advanced-table.html` - Working with HTML tables
  - `week04/array-function.html` - Array methods and functions
  - `week04/lazyload.html` - Lazy loading for performance optimization
- **Scripts**: Array manipulation functions, lazy loading implementation
- **Focus**: JavaScript arrays, DOM manipulation, performance optimization

#### **Week 05: Browser Object Model (Extended)**

- **File**: `week05/bom.html`
- **Focus**: Advanced BOM concepts and window object manipulation

### 🏢 Main Course Project

The `project/` folder contains a comprehensive website project with multiple features:

#### **Project Structure**

- **Main Pages**:
  - `index.html` - Homepage with daily content
  - `about.html` - About page
  - `contact.html` - Contact form page
  - `events.html` - Events listing with slider
  - `quiz.html` - Interactive quiz
  - `reference.html` - Reference materials
  - `siteplan.html` - Site plan and structure

#### **Catalog Section** (`project/catalog/`)

- `index.html` - Catalog homepage
- `books.html` - Books catalog with JSON data integration
- `formulas.html` - Formulas reference
- Data sourced from `project/data/books.json`

#### **Data Files** (`project/data/`)

- `books.json` - Book catalog data
- `community.json` - Community information
- `daily.json` - Daily content data
- `events.json` - Events information
- `quiz.json` - Quiz questions and answers

#### **Features Implemented**

- **Dynamic Content**: Using JSON data files and JavaScript rendering
- **Events Slider**: Interactive event carousel (`eventsSlider.js`)
- **Quiz Functionality**: Interactive quiz system with scoring
- **Navigation**: Dynamic menu system (`menu.js`)
- **Responsive Design**: Mobile-first design with responsive layouts
- **Content Population**: JavaScript utilities to dynamically populate content
