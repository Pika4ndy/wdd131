Site Plan for the Website Project

SciSphere Library

This name represents a place where people can gather to read and talk about science.

Domain Name: scisphere-library.org

Purpose

The site will provides registration for the library, shows list of book available, allow user to read/reserve/order a book online, announce events and other kind of activities of the library.

Scenarios

  • Where is this library located?
  • What fields of science does it talk about?
  • When is it open?
  • Why this organisation?
